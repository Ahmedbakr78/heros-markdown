# Heros Markdown v1.2.0 — 110 free tools, study studio complete

A fast, private, free and unlimited Markdown studio for Chrome, Edge and Brave — with the complete app experience on mobile via Kiwi Browser.

## Highlights

- Perfect rendering of newlines, GitHub Flavored Markdown, footnotes, callouts, collapsible blocks and automatic contents
- Offline LaTeX mathematics in all four delimiter forms with bundled KaTeX fonts
- Every Mermaid diagram type rendered in a queue, themed, with clean error panels and SVG export
- Every language: Arabic, Hebrew, Persian and Urdu automatic right-to-left, CJK word counting, Unicode search
- Marker Studio: select text, then highlight, underline or strike with seven colors, per-file panel and export
- Flashcards generated automatically from headings, question and answer pairs, bold terms and cloze blanks, with cloze quiz and Anki TSV import and export
- Task manager with priorities, due dates, filters, checklist import and export
- Stopwatch with saved laps, tally counters, habit tracker with streaks, Pomodoro focus timer
- Backup everything into one JSON file and restore it in one step
- Full Heros PDF studio design: white and dark themes, bottom status bar, responsive drawer on mobile

## Removed in this version

- The command palette window, replaced by the searchable features list opened with the F key
- The read-aloud text-to-speech feature and all of its controls, by design

## Install in two minutes

1. Download the ZIP attached to this release and unzip it.
2. Open `chrome://extensions` and enable Developer mode.
3. Choose Load unpacked and select the folder.
4. For local files, enable Allow access to file URLs on the extension details page.
5. Click the toolbar icon, or open any Markdown link, to start.

## Mobile

Install Kiwi Browser on Android, open `chrome://extensions` inside it, enable Developer mode and load the unzipped folder. All 110 tools work with touch. On iOS, export study packs as Markdown and read them in any Markdown app.

## Privacy

One hundred percent offline. No accounts, no telemetry, no uploads. Storage stays on the device in IndexedDB and localStorage. Uninstalling removes all data, so back up first.
