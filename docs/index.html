Install in two minutes

  1. Download the repository ZIP from GitHub and unzip it.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the Heros_Markdown folder.
  4. For local files, open the extension details and enable Allow access to file URLs.
  5. Click the toolbar icon, or open any Markdown link, to start.
  6. Press F inside the app to search all 110 tools.

Full app on mobile

Chrome on phones does not load extensions, so the complete application runs on Kiwi Browser.

  1. Install Kiwi Browser on Android from the Play Store.
  2. Open chrome://extensions inside Kiwi and enable Developer mode.
  3. Choose Load unpacked and select the unzipped folder.
  4. Use the toolbar menu to open Heros Markdown. All 110 tools work with touch.
  5. Tip: export study packs as Markdown to read notes in any mobile Markdown app.

Frequently asked questions

Is it really free and unlimited?

Yes. MIT licensed, all 110 tools, unlimited documents, no accounts and no paywalls.

Are my files uploaded anywhere?

No. Rendering and storage happen entirely on your device using IndexedDB and localStorage. Only addresses you open are fetched.

A local Markdown file will not open. What now?

Enable Allow access to file URLs on the extension details page, or use Choose file and drag-and-drop which need no extra permission.

Why does a very large file feel slow at first?

Performance mode paints the text immediately and skips heavy math and diagrams. Toggle them back on in the Tools tab for the complete render.

How do I keep my marks and tasks safe?

Use Backup all in the Hub. It writes one JSON file with everything, and Restore reads it back completely.

Does the read-aloud feature exist?

Heros Markdown focuses on visual studying with markers, cards and quizzes. Text-to-speech was removed by design in version 1.2.

Can I style the app myself?

Yes. The Tools tab has a custom CSS editor that applies styles instantly and stores them per device.
